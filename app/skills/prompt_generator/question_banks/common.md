| 问题 | 为什么要问 |
|------|-----------|
| 这是哪门课？有老师给的guideline或rubric吗？ | 评分标准决定一切取舍 |
| 个人还是小组？几个人？你负责哪部分？ | 决定范围和分工 |
| 截止日期是什么时候？中间有没有阶段性提交？ | 决定方案的复杂度上限 |
| 你的目标是什么：高分、及格、学技能、还是做作品集？ | 决定在哪里多花力气 |
| 你现在已经做到哪一步了？有已有的代码/草稿吗？ | 避免从头推翻已有工作 |
| 老师或助教有没有特别强调过什么？ | 隐含评分点 |
| 有没有不能用的工具、库或方法？ | 硬性约束 |
| 最终要交什么：代码、报告、视频、演示、还是几样都要？ | 交付物清单 |
